# Design Tokens & Visual Constraints

## Color Palette
- **Primary Background**: #121212 (Deep Charcoal)
- **Secondary Background**: #1A2238 (Navy Slate)
- **Accent Color**: #2b88c6 (Professional Blue)

## Layout Standards
- **Behavior**: Fluid, full-width using CSS Grid/Flexbox.
- **Hero Section**: Profile photo on the RIGHT with CSS gradient mask; text on the LEFT.
- **Project Cards**: 'Image-Overlay' style where titles appear on hover.
