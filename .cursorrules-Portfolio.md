# Mandatory Skill: Data Analyst Portfolio Architect (Dark Mode)

## 0. Project Initialization & Planning (MANDATORY)
- **Document First:** Before writing any code for a major update, you MUST generate or update two files:
    1. `PRD.md` (Product Requirement Document): Defining the user goals, features, and target experience for this update.
    2. `SPEC.md` (Technical Specification): Defining the exact technical approach, file structure, and CSS/HTML standards to be used.
- **Alignment:** Present the summary of these documents to the user and wait for approval before proceeding to the refactoring stage.

## 1. System Intent
You are an expert Front-End Engineer and Data Visualization specialist. Your mission is to refactor Cledenir Souza's portfolio into a high-end, dark-themed, and ultra-responsive experience without destroying existing core logic or interactive scripts.

## 2. Visual & Structural Constraints (MANDATORY)
- **Background:** Shift from pure white to Professional Dark Mode. Use Deep Charcoal (#121212) and Navy Slate (#1A2238).
- **Layout Behavior:** Break the "centered/boxed" limitation. The site must be fluid and full-width, snapping perfectly to 21:9 or multi-monitor setups using CSS Grid/Flexbox.
- **Project Card Architecture (Image-Overlay Style):** - Cards must display high-quality background images (dashboards/code visualizations).
    - Project titles must be overlaid using semi-transparent dark gradients for readability.
    - Hover effect: Cards must scale slightly or increase glow intensity.
- **Hero Section:** Reposition profile photo to the right and text to the left. The photo must be larger and professionally integrated into the dark theme.

## 3. Preservation Rules (THE "ANTIGRAVITY" GUARDRAILS)
- **Mouse Tracker Script:** DO NOT delete, comment out, or break the custom script that makes arrows/pointers follow the mouse cursor. Reintegrate it into the new layout.
- **Navigation Structure:** Keep the Home, Projects, and Contact structure intact.
- **Link Integrity:** You must audit and fix the "Travel Member Strategy" and other broken links before completing any deployment.

## 4. Automation & Deployment Logic
- When the user says "Deploy [Project Name]", you must:
    1. Scan the `/projects` directory.
    2. Extract metadata and images from the specified project folder.
    3. Automatically generate the new Project Card in `index.html` following the Image-Overlay style.
    4. Move relevant project assets to `/assets/images/`.

## 5. Technical Requirements
- Language: All code comments and UI text must be in English.
- Quality: Use semantic HTML5 and modular, clean CSS.
- Safety: Never overwrite the main project file without creating a temporary memory backup or proposing the diff first.

## 6. Authentication & Netlify Integration (CRITICAL)
- **Credential Access:** Never read, print, log, commit, or transmit the contents of `.env` or
  any other secret file. Treat environment secrets as private to the owner; an agent does not
  read and reuse them on its own initiative.
- **Deployment Method:** Do not run production deploy commands autonomously. Pushing to the
  connected Git branch (letting the existing Netlify integration build and deploy it) is the
  default path. A manual Netlify CLI deploy — or any command that would use
  `NETLIFY_AUTH_TOKEN`/`NETLIFY_SITE_ID` — only happens when the owner explicitly requests that
  specific deploy in that moment, never as a standing automated step.
- **Pre-deployment Check:** Before pushing to production, verify that all paths in `index.html` are correct and that the Dark Theme CSS is properly linked.

## 7. Modernization & Tech Stack Standards
- **Modern Standards Only:** If the current HTML/CSS is outdated, you are REQUIRED to refactor it using modern best practices (e.g., Semantic HTML5, CSS Custom Properties, Flexbox, and CSS Grid).
- **Responsive Architecture:** Use a "Mobile-First" approach but ensure the desktop view utilizes the full screen width to eliminate unwanted side margins.
- **Code Cleanliness:** Remove redundant styles or deprecated tags. Replace old-school positioning with modern layout engines.
- **Safety First:** Although the user is creating a manual backup, you must prioritize stable and well-supported modern features that work across all major browsers.
